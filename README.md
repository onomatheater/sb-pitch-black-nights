# Spaced Breakout Dark Nights

Completely dark nights on all surfaces (Nauvis, planets, space platforms). Clean-room implementation, MIT.

Visual only — does not change solar power or day length.

## Factorio portal upload

1. Zip the repo contents as `spaced-breakout-dark-nights_1.0.0.zip` (zip must contain the folder, not loose files)
2. Upload at https://mods.factorio.com/mod/spaced-breakout-dark-nights (or new mod page)
3. Set Factorio version 2.0, category Tweaks
